# Citation

This repository documents the ITI–gITI–IDI framework developed by Jim Y. Huang as part of a broader research programme on Fiscal Geometry, institutional continuity, relational measurement, and institutional divergence.

The framework separates:

- **ITI** — independently generated quantitative institutional tension;
- **gITI** — independently reconstructed relational or topological institutional tension;
- **IDI** — the aligned distance between ITI and gITI;
- **D** — signed divergence between the two measurement paths.

The first empirical application is the Lehman Brothers longitudinal case.

## Related Research

The repository is connected to the broader Fiscal-Geometric model of institutional existence and continuity:

**Fᴳᶜ = X × Y**

where:

- **X** denotes horizontal execution and carrying capacity across contemporaneous institutional space;
- **Y** denotes vertical carrying capacity through time.

The Lehman application tests whether observable quantitative institutional condition and the relational capacity required to reproduce that condition can diverge before terminal failure.

## Empirical Status

The current Lehman empirical result is classified as:

**CONDITIONAL SUPPORT**

The strongest current finding is that late-window reductions in leverage-visible institutional tension were not accompanied by an equivalent reduction in relational strain.

The framework is not presented as a bankruptcy-prediction model or universal failure-threshold system.
